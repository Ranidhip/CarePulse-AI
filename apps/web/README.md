# CarePulse AI — Provider Web Dashboard

This folder is intentionally empty except for this README. The actual app
is generated by Vite's own CLI, which needs network access — run this on
your machine, not something I can do for you in advance.

## Scaffold it

From inside `apps/web/`:

```bash
npm create vite@latest . -- --template react-ts
```

It may warn the folder isn't empty (because of this README) — choose
**"Ignore files and continue"**.

Then install the extra libraries the architecture plan calls for:

```bash
npm install @mui/material @emotion/react @emotion/styled
npm install react-router-dom
npm install
```

## Run it

```bash
npm run dev
```

Opens at http://localhost:5173 by default.
