ADDED (new files):

  backend/app/services/ai/client.py
    - get_openai_client(): plain function (not a FastAPI Depends) that
      constructs OpenAI(api_key=..., timeout=..., max_retries=...) from
      settings. Deliberately not Depends()-injected — see the file's own
      docstring: constructing a client with a missing API key must never
      happen on every request regardless of whether AI is enabled.
    - verify_model_available(client, model): used by
      check_openai_model.py. Never raises; returns (bool, message).

  backend/app/services/ai/analysis.py
    - run_ai_analysis(client, *, model, difficulty_text, missed_doses,
      missed_dose_count, medication_stopped, supply_remaining) ->
      AIAnalysisOutcome. The actual adapter: one Responses API call,
      wrapped in exception handling for NotFoundError / RateLimitError /
      APITimeoutError / any other OpenAIError / any unexpected error, plus
      explicit checks for response.status, refusal detection, and a
      second independent Pydantic revalidation pass on top of whatever
      .parse() already validated. Never raises to its caller — every
      failure path returns a status="failed" outcome with an error_code,
      never an exception, never patient free-text in logs.
