CarePulse AI — Phase 5 provider agent-workflow APIs
===================================================

Implemented endpoints
---------------------

1. GET /provider/patients/{patient_id}/agent-runs
   - Requires provider authentication and an active patient assignment.
   - Returns run status/timestamps and safe action summaries.
   - Does not select or return model names, internal error codes, prompts,
     tool inputs, tool outputs, or raw model payloads.

2. GET /provider/follow-up-tasks
   - Requires provider authentication.
   - Returns unclaimed tasks and the current provider's tasks only for
     actively assigned patients.
   - Optional filter: ?status=pending|in_progress|completed|dismissed
   - Hides tasks already owned by another provider.

3. PATCH /provider/follow-up-tasks/{task_id}
   - Requires provider authentication, an active patient assignment, and
     either an unclaimed task or a task already owned by this provider.
   - Claims an unclaimed task when it advances.
   - Allowed transitions:
       pending -> in_progress | dismissed
       in_progress -> completed | dismissed
       completed and dismissed are terminal
     Repeating the current state is an idempotent success.
   - Uses an atomic owner/status compare-and-set to prevent concurrent
     double claims and stale updates.
