# CarePulse AI

Hypertension medication-adherence and patient follow-up decision-support prototype.
Academic MVP — **not a medical device**. Does not diagnose, prescribe, or change dosages.

Build window: 4–25 Aug 2026. See `docs/00-scope-freeze.md` for the locked MVP scope.

## Project layout

```
CarePulse-AI/
├── apps/
│   ├── mobile/          # Patient app — Expo + React Native + TypeScript
│   └── web/               # Provider/admin dashboard — React + Vite + TypeScript + MUI
├── backend/
│   └── app/                # FastAPI backend (single deployment, modular by domain)
│       ├── api/              # Route handlers, one module per domain (auth, patients, checkins...)
│       ├── core/             # Config, security, Supabase client setup
│       ├── models/           # Pydantic request/response + DB models
│       ├── services/
│       │   ├── rules/         # Deterministic risk-rule engine (versioned, safety floor)
│       │   └── ai/            # OpenAI adapter — evidence + summary only, never diagnoses
│       └── tests/
├── supabase/
│   └── migrations/         # SQL migrations (added once the ERD is finalized)
├── packages/
│   └── shared-types/       # TypeScript types shared by apps/web and apps/mobile
└── docs/                    # Scope freeze, ERD, API spec, safety docs, test plan
```

## Setup order

Each subfolder has its own README with exact commands, because the actual
app scaffolds (Expo, Vite) need to be generated by their own CLI tools on
your machine — see `apps/web/README.md`, `apps/mobile/README.md`,
`backend/README.md`, and `supabase/README.md`.

1. `backend/` — Python virtual environment + FastAPI (instructions in `backend/README.md`)
2. `apps/web/` — Vite + React + TypeScript + MUI
3. `apps/mobile/` — Expo + TypeScript
4. `supabase/` — link to your Supabase project

## Safety note for contributors

Deterministic rules in `backend/app/services/rules/` are the safety floor.
AI in `backend/app/services/ai/` may only add evidence/summary and can never
lower a rule-derived risk level. See `docs/00-scope-freeze.md` section 5.
